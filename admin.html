📖 批次功能操作說明

適用於企業批次建卡、照片上傳、CTA 管理等作業

① 📷 先上傳員工照片（取得圖片連結）
1. 展開「📷 照片壓縮上傳」區塊
2. 選擇壓縮設定：最大寬度 600px、品質 80%（預設即可）
3. 點「📂 選取照片」→ 一次選取所有員工照片
4. 點「☁️ 開始壓縮並上傳」→ 系統自動壓縮後存入雲端
5. 點「📥 匯出 Excel」→ 取得每張照片的網址
💡 這些網址等一下要填入建卡 Excel 的 avatar_url 欄
② 🏢 批次建卡
1. 點「📥 下載 Excel 範本」，用 Excel 開啟
2. 按順序填入資料（負責人排第一行，再填區域卡，最後填員工）：
• type：負責人 / 北區 / 中區 / 南區 / 員工
• name：姓名（必填）
• title：職稱　• company：公司　• phone：電話
• email　• line_id　• avatar_url：照片網址（步驟①取得）
• plan：premium / free　• color：p1~p7（見顏色參考）
• region：員工必填所屬區域（北區／中區／南區）
• price：建卡費用（選填）
3. 存檔後點「📂 上傳 Excel」選取檔案
4. 預覽確認無誤後，點「🚀 開始批次建卡」
5. 等待完成後，點「📥 匯出建卡結果」保存卡號對照表
💡 系統會自動產生卡號（TW####），並把區域卡與員工卡的關聯設定好
③ 🔗 設定區域卡的員工按鈕（批次 CTA）
1. 展開「🔗 批次 CTA 管理」區塊
2. 在「要設定 CTA 的卡號」填入區域卡號（如北區服務站的卡號）
3. 在「⚡ 快速產生員工連結」填入負責人卡號，點「⚡ 自動產生」
4. 系統自動列出所有員工姓名＋卡片連結
5. 確認名單後點「💾 儲存」
6. 北區／中區／南區各做一次
💡 這樣區域卡上就會出現員工的 CTA 按鈕，點名字跳到員工名片
④ 📦 批次匯出交付連結
1. 展開「📦 批次交付連結匯出」區塊
2. 填入負責人卡號，點「📦 查詢並匯出」
3. 自動下載 Excel，內含每位員工的：
• 名片連結：客戶看到的名片網址
• 交付卡連結：員工自己管理名片用的私人連結
• 到期日
4. 把 Excel 交給主管，依此傳給各員工
⑤ ✏️ 批次更新名片資料
1. 展開「✏️ 批次更新名片資料」區塊
2. 點「📥 下載更新範本」，填入要修改的欄位（card_id 必填，其他欄位留空表示不更新）
3. 上傳 Excel → 預覽 → 點「✏️ 開始批次更新」
⑥ 🔄 批次續約
1. 展開「🔄 批次續約」區塊
2. 點「📥 下載續約範本」，填入要續約的卡號（card_id 必填，price 選填）
3. 上傳 Excel → 預覽 → 點「🔄 開始批次續約」
4. 系統自動延長 365 天，並寫入付款記錄

🏦 銀行對帳操作說明

每天把銀行轉帳記錄上傳，系統自動找到對應的客戶並開卡

⚠️ 前提：客戶必須先填過「付款確認單」（card_id + 金額 + 末五碼），系統才能比對成功。
如果客戶還沒填，這筆銀行記錄會顯示「❌ 找不到對應確認單」，等客戶填完後再重跑一次即可。
① 準備銀行明細
1. 點「📥 下載銀行明細範本」，用 Excel 開啟
2. 把當天銀行轉帳記錄填進去：
• 入帳日期：如 2026-05-24（選填）
• 入帳金額：轉入金額，如 1500（必填）
• 末五碼：匯款帳號後五碼，如 12345（必填）
• 備註：自己備注用，如「王小明」（選填）
3. 存檔（.xlsx 格式）
② 上傳並比對
1. 點「📂 上傳銀行明細 Excel」，選取剛填好的檔案
2. 預覽確認資料正確
3. 點「🔍 開始比對」→ 系統自動找對應客戶
③ 查看比對結果
比對結果有三種狀態：
✅ 比對成功 找到對應客戶，可以開卡
⚠️ 多筆符合 金額和末五碼有多人相同 → 用下拉選擇正確卡號
❌ 未比對 客戶尚未填確認單，或金額/末五碼有誤
④ 確認開卡
1. 確認「✅ 比對成功」的項目無誤
2. 點「✅ 確認匯入已比對項目並開卡」
3. 系統自動寫入付款記錄，並觸發開卡
4. 完成後重整「付款中心」確認結果
💡 ❌ 未比對的不會匯入，等客戶填完確認單後再重跑一次
